Token 仅用于当前标签页会话；点击「断开连接」即可清除。不会写入网页或仓库。

怎么生成 Token？
  1. 打开 GitHub 的 Fine-grained token 创建页。
  2. Repository access 选择 Only select repositories，选中这个作品集仓库。
  3. Permissions → Repository permissions → Contents 设为 Read and write。
  4. 生成后复制 github_pat_... 到上面的输入框。

建议为这个仓库单独创建一个有到期时间的 Token。

这个页面本身是公开的，但没有 Token 的人只能本地查看，无法提交。不要把 Token 发给别人，也不要把 Token 写进仓库。
